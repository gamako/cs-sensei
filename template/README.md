# 学習用の作業リポジトリ

自分の技能の「一歩外側」を見つけて、手を動かして学ぶための作業場所です。

**コンピュータサイエンス・ソフトウェア工学の原理的な考え方を学びます。**
自分の実務や関心のある題材を入口にして、題材が変わっても通じるものを一つずつ扱います。
フレームワークの使い方や運用の作法は扱いません。

コーディングエージェントは、ここでは実装を代行する役ではなく、**本人に手を動かさせる役**を務めます。
答えを先に出さず、まだ入っていない領域を課題に変え、走り切るまで付き添います。
振る舞いの詳細は [AGENTS.md](AGENTS.md) に書いてあります。

## 始め方

エージェントを起動して、「学習を始めたい」と言うだけです。

```bash
claude     # または codex / copilot
```

行き先が決まっているなら、そう伝えてください。

```
コンピュータアーキテクチャ方面で学びたい
```

指定しなければ、エージェントが決めて「題材は X、学ぶのは Y、まず作るのは Z」と
宣言してから始めます。分かっている前提として置いたものも一緒に言うので、
**違うと思ったら、その場で言ってください。**
黙って始めないための宣言なので、流されると意味がなくなります。

## 再開するとき

同じことを言えば済みます。`log/` を読んで前回の「次に試すこと」から再開するので、
毎回ゼロから聞き直されることはありません。

**今どこにいるかは `log/` が持っています。** この README には書きません。
更新が要る欄を置くと、更新されずに嘘になります。

## 構成

```
├── AGENTS.md    エージェントの振る舞いを決める文書
├── log/         学習記録。セッションごとに 1 ファイル
└── work/        課題の作業場所
```

## 実務のコードを見せる場合

エージェントがパスを聞いてくるので、読ませたいリポジトリのパスを答えてください。
読み取りの許可も必要です。見せなくても進められます。

過去のエージェントセッションの履歴も材料になります。何を繰り返し聞いたか、
どこを丸投げしたかが出るので、自己申告より雄弁です。
どちらも読む前に断りが入ります。
